****************************************************
GIFTS Gamma-ray Data Tools Documentation
****************************************************

.. figure:: images/gdt-gifts_logo.png

The `GIFTS Gamma-ray Data Tools (GDT) <https://github.com/GIFTS-6U/gdt-gifts>`_ is a toolkit for GIFTS data products, which is built on the 
:external:ref:`GDT Core Package<gdt-core>` and :external:ref:`Fermi Gamma-ray Data Tools<gdt-fermi>`. 

Gamma-ray Investigation of the Full Transient Sky (GIFTS) is a 6U CubeSat under development, whose mission aim 
is the detection and localization of gamma-ray bursts (GRBs) from low Earth orbit in the multi-messenger 
era. The GIFTS instrument comprises six cerium bromide (:math:`\mathrm{CeBr}_3`) scintillator detectors with different
orientations, which are arranged into two three-detector clusters within the CubeSat housing,
and will have the capability to detect gamma rays in an energy range of approximately 30 keV to 2 MeV.
The current toolkit is a prototype that services an `exemplar GIFTS catalog containing simulated GIFTS data products <https://zenodo.org/records/17295200>`_ 
generated during 
payload processing pipeline development. This exemplar catalog illustrates the expected contents of the 
the public data catalog that will be provided following the GIFTS mission launch, which will also be accompanied
by corresponding future versions of the toolkit.


.. note::

   The current version of the toolkit is intended to be illustrative of the expected post-launch version,
   with the implementation and documentation intentionally inspired by and similar to that of the :external:ref:`Fermi Gamma-ray Data Tools<gdt-fermi>`.
   It is envisaged that the toolkit and documentation will be significantly revised in future releases.

   All :ref:`GIFTS data product types <gifts-data-types>` are described using products contained in the 
   :ref:`current exemplar GIFTS burst catalog <gifts-catalogs>`, which were created using the approach described in 
   `O'Callaghan et al., CubeSat Payload Processing Pipeline Development For Gamma-Ray Burst Detection (2026) (will be updated following publication) <http://2026_GIFTS_paper>`_.
