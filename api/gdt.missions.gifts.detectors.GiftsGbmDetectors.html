GiftsGbmDetectors¶

class gdt.missions.gifts.detectors.GiftsGbmDetectors(value, names=None, *, module=None, qualname=None, type=None, start=1, boundary=None)[source]¶

Bases: Detectors

The GIFTS and GBM Detector name and orientation definitions.

This is used for analysis that combines both detectors e.g. localization plots.
